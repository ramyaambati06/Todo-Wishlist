# Todo Wishlist App

A modern and responsive productivity web application built using HTML, CSS, and JavaScript that helps users manage daily tasks and personal wishlist goals in one place.

## Features

* Add daily tasks
* Mark tasks as completed
* Manage personal wishlist items
* Clean and responsive UI
* Interactive task handling

## Tech Stack

* HTML5
* CSS3
* JavaScript
